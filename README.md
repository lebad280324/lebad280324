- Docker Compose
- REST API integration

An AI assistant that allows users to request business reports using natural
language while accessing controlled PostgreSQL analytics views.

Main technologies:

- FastAPI
- PostgreSQL
- SQLGlot

Status: Prototype and in development

- Scheduled email processing
